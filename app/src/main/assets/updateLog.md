# 玄卷更新日志

## v0.1.8

### 书源扩充

- 新增猪八戒小说网、从联好小说、GreatlyName 小说 3 个内置书源，内置书源总数由 37 增至 40。
- 三个新源均以《腐朽世界》（滚开）完成严格在线验收：搜索与详情准确、封面为真实图片、目录均超过 500 章，并实际读取首章及约 75% 位置的后段正文。

### 更新日志修复

- 修复版本升级后首次进入玄卷仍显示 Legado 上游更新日志的问题，升级弹窗现在只读取并展示玄卷自己的版本说明。
- 「关于 → 更新日志」与升级后首次启动弹窗统一使用同一份玄卷日志，避免两个入口内容不一致。
- 新增版本日志契约检查：应用默认版本号升级后，如果更新日志首个版本号没有同步更新，单元测试会直接失败，防止以后再次漏改。

### 听书控制台 2.0

- 重做阅读页听书控制面板，统一为玄卷暖棕暗金播放器式界面；播放/暂停作为主操作突出显示，上一段、下一段、停止、上一章、下一章继续保留，并扩大主要操作的触控区域。
- 针对“听书页面太黑、看不清”进一步提高底板、卡片、按钮、主/次级文字对比度，朗读设置页同步使用更亮的暖棕高对比卡片；墨水屏继续使用独立高对比逻辑。
- 简化睡眠定时：移除旧的定时滑杆和“保存默认时间”混合交互，只保留一个明确的睡眠定时入口；面板会直接显示“未设置”“N 分钟后停止”或“听完 N 章后停止”。
- 新增 0.8×、1.0×、1.2×、1.5×、2.0× 五档常用倍速，同时保留原有细粒度语速滑杆；跟随系统语速时会自动禁用自定义倍速控件，避免状态冲突。
- 修复朗读语速加减可能越过滑杆有效范围的问题，语速配置在读取、保存和控制台操作三层统一限制在有效区间。
- 新增“回到朗读位置”：手动翻页离开当前朗读段落后，可以从听书控制台直接回到正在朗读的位置；原阅读页浮动回跳入口继续保留，二者按当前界面状态互斥显示。
- 朗读高级设置重新整理为“播放与控制 / 阅读跟随 / 引擎与网络”三组，保留原有 TTS 引擎、系统 TTS、音频焦点、来电暂停、唤醒锁、翻页跟随与流式音频等配置。
- 补充窄屏自适应与墨水屏高对比兼容；新增听书控制台、回跳、定时、跟随与无障碍相关回归测试。

### 免费离线多角色朗读

- 新增「玄卷离线 · Kokoro」朗读引擎，基于 sherpa-onnx 在手机本地运行神经网络 TTS；模型安装完成后断网即可朗读，不需要 API Key、账号、次数额度或付费服务，原有系统 TTS 与 HTTP TTS 继续保留作为兼容选项。
- Kokoro 模型不打进 APK。首次启用时由应用单独下载 `kokoro-int8-multi-lang-v1_1` 到应用私有目录，解压后约 215 MB；下载过程使用前台通知显示进度，完成后校验模型、词典、FST 与语音数据，安装失败不会替换已有可用模型。
- 新增离线多角色分轨：正文旁白、男性角色对白、女性角色对白、无法确认角色的对白可以分别绑定不同的 Kokoro 中文音色；中文女声音色范围为 3–57，男声音色范围为 58–102。
- 角色判断采用保守规则：识别引号对白，并结合“说道 / 问道 / 喊道 / 她 / 男子 / 女子”等邻近明确线索判断角色类型；仅出现姓名但没有可靠性别线索时统一使用“未知对白”音色，不根据姓名强行猜测。
- 新增本地音频播放服务，支持听书暂停/继续、上下段、上下章、语速变化、阅读位置同步、睡眠定时和媒体通知等现有控制；音频由 Kokoro 在设备 CPU 本地生成后直接播放，正文无需上传服务器。
- 增加角色分段、模型完整性、离线引擎路由、模型安装流程与原有听书界面的回归检查；当前调试 APK 已确认包含 sherpa/ONNX Runtime 原生运行库，同时未包含 Kokoro 模型文件。

### 版本内容确认

- 延续 v0.1.7 已完成的内置书源整合成果，并在 v0.1.8 增加 3 个严格实测源，内置书源总数达到 40 个；升级时保留用户已有的启用状态、发现开关、排序、权重和响应时间等设置。
- 最后 7 个新增书源继续按严格在线标准验收：精确搜索《腐朽世界》/滚开、详情正确、真实封面可获取且非占位图、目录不少于 500 章，并验证首章与约 75% 位置后段正文均可正常读取。

## v0.1.7

### 书源扩充

- 新增 24 个社区书源并纳入玄卷内置管理，内置书源总数由 13 个扩充到 37 个。
- 新增源按社区规则池分组整理，升级后继续保留用户已有的启用状态、发现开关、排序、权重和响应时间等设置。
- 内置书源迁移版本提升到 20，旧安装升级后可以自动补齐新增内置源，同时不会覆盖用户自定义书源。

### 可用性与封面验收

- 对新增书源补齐搜索、详情、目录、正文与封面规则契约，并完成分批可用性与真实封面验证。
- 最后 7 个书源按严格在线标准完成全链路验收：精确搜索《腐朽世界》/滚开、详情信息正确、真实封面可直接获取且不是占位图、目录不少于 500 章。
- 严格验收同时检查首章正文与约 75% 位置的后段章节正文，确认不仅能搜索和打开详情，也能持续正常阅读。

### 稳定性保障

- 新增社区内置书源契约测试、真实封面检查与严格在线探针，降低后续书源规则失效后仍被误认为可用的概率。
- 升级过程保留已有书源个性化状态，避免版本更新后重新启用、重新排序或覆盖用户配置。
